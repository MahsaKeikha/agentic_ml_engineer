# Agents, Tools, and Skills

F31 separates ML engineering roles from reusable skills and deterministic tools.

**Agents:** Data Assessment, Modeling Strategy, Evaluation, Reproducibility Auditor, Deployment Handoff.

**Skills:** data-readiness assessment, model strategy selection, model evaluation, reproducibility audit, deployment handoff.

**Tools:** dataset profiling, metric summarization, reproducibility fingerprinting.
